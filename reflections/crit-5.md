# Crit 5 reflection

Session facts, for context before answering the two prompts below: this
deliverable is **PIE HALL 98**, an original Canvas 2D pseudo-3D raycasting
shooter (four oversized school-hall rooms, seven mascot/robot enemies, a
cream disc launcher, hitscan-vs-projectile combat, win/loss loop, no menu or
on-screen text). Most art is procedurally generated at runtime; a small,
curated set of real CC0 sprites and sound effects was layered on top later
(see `THIRD_PARTY_ASSETS.md`), with async loading and a procedural fallback
if a file fails to load. Full build history is in `PROCESS.md`; commits
`b98e41c`, `42a3432`, `27c4738`, `526fc64`, `b6741ea`, `d6f4fec`, `6ba841e`,
`3fb4fa9`.
